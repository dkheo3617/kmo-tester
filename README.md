# KMO/영재고 테스트기 (웹 버전)

주소: https://dkheo3617.github.io/kmo-tester/

- Google 계정으로 로그인하면 시험·명단·결과·교재가 Firebase(seobusansheet, `kmo/{uid}/`)에 저장되어 어느 기기에서나 같은 자료를 씁니다.
- AI 키는 기기(브라우저)마다 「설정」에서 넣습니다(클라우드에 올리지 않음).
- `index.html` 한 파일로 된 앱입니다. 같은 파일을 컴퓨터에서 바로 열면(file://) 그 브라우저에만 저장하는 방식으로 동작합니다.
- 원본은 작업 세션의 app3_src.html + build3.py 로 만듭니다.
